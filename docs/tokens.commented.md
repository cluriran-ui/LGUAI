# [기획] tokens.json 읽는 법

> [기획] `docs/tokens.json`은 JSON(데이터를 적는 파일 형식)이라 주석을 넣을 수 없음.  
> 원본은 그대로 두고, 같은 내용을 기획자용 설명과 함께 이 문서로 정리함.  
> 근거: `docs/Design.md` 1 ~ 3장 (색·글자·간격 규칙), `reference/links.md` 우선순위

---

## [기획] 이 파일은 무엇인지

- 화면에 쓰는 색·글자 크기·간격·모서리 둥글기 값을 한곳에 모아 둔 "디자인 값 목록"임
- 각 값에는 이름표가 붙어 있음. 이 이름표를 **토큰**(디자인 값에 붙인 이름)이라고 부름
  - 예: `text/primary` = "제목·본문 글자색" = `#181A1B`(거의 검정)
- 화면을 만들 때는 색 번호를 직접 쓰지 않고 이름표만 씀. 색을 바꿀 때 이 파일만 고치면 전 화면에 반영됨
- 색 번호 읽는 법: `#` 뒤 6자리가 색, 8자리면 마지막 2자리가 투명도
  - 예: `#0000001A` = 검정을 10%만 진하게(거의 투명하게) 칠함

## [기획] 파일 구성 (5묶음)

| 묶음 | 원본 위치 | 쉬운 설명 |
|---|---|---|
| primitive | 2 ~ 20줄 | 기본 물감 17개. 색 이름과 진하기 번호만 있음 |
| semantic | 21 ~ 174줄 | 역할별 이름표 38개. "어디에 쓰는 색인지"로 이름 붙임 |
| typography | 175 ~ 187줄 | 글꼴 이름과 글자 크기 10단계 |
| spacing | 188 ~ 207줄 | 요소 사이 간격 18단계 |
| radius | 208 ~ 224줄 | 모서리 둥글기 15단계 |

- primitive와 semantic의 관계: semantic(역할 이름표)이 primitive(물감)를 하나씩 가리킴
  - 예: `fill/primary`(주요 버튼 배경) → `pink/500`(브랜드 분홍) → `#FF2E98`

## [기획] 2. semantic — 역할별 이름표 (21 ~ 174줄)

- 이름 규칙: `무엇에/어떤 역할`. 예: `text/error` = 글자 중 오류 문구용
- "쓰는 곳"은 `Design.md` 1장 기준. "사용처 미확인"은 정의만 있고 실제 화면 부품에 쓰인 곳이 확인되지 않은 것

### [기획] 2-1. 글자색 (text)

| 이름표 | 물감 | 쓰는 곳 |

| text/primary | gray/900 | 제목, 입력한 값, 요금, 일반 본문 |

## [기획] 4. spacing — 간격 (188 ~ 207줄)

- 요소와 요소 사이, 또는 상자 안쪽 여백의 크기. 단위는 px(화면 점 하나 크기)
- 정의된 값 18개: 0, 2, 4, 6, 8, 10, 12, 16, 20, 24, 28, 32, 40, 48, 56, 60, 64, 80
- 원본은 순서가 섞여 있음 (예: 80 다음에 10). 값 자체는 `Design.md`와 같음

| 값 | 주로 쓰는 곳 (`Design.md` 3장) |
|---:|---|
| 4 | 작은 안쪽 간격, 상단 제목줄 위아래 여백 |
| 8 | 카드 안 간격, 버튼 사이 간격 |
| 12 | 구역 안 간격, 정보 행 위아래 여백 |
| 16 | 신청·완료 화면 바깥 여백, 상단 제목줄 좌우 여백 |
| 20 | 요금제 카드·요금 카드 안쪽 여백 |
| 24 | 목록·상세 화면 바깥 여백, 버튼 좌우 여백 |
| 32 | 하단 버튼 영역 아래 여백 (휴대폰 하단 막대 자리) |

## [기획] 5. radius — 모서리 둥글기 (208 ~ 224줄)

- 숫자가 클수록 모서리가 둥긂. `radius/full`(9999)은 양 끝이 완전히 둥근 알약 모양
- 정의된 값 15개: 0, 2, 4, 5, 6, 8, 10, 12, 16, 20, 24, 32, 40, 999, full(9999)

| 값 | 주로 쓰는 곳 (`Design.md` 3장) |
|---:|---|
| 0 | 상단 제목줄, 입력란 (각진 모양) |
| 4 | 혜택·패키지 표시 |
| 6 | 할인 표시 |
| 8 | 버튼 |
| 12 | 요금 카드, 선택지 |
| 16 | 요금제 카드 |
| 999 | 추천 표시 |
| full | 필터 버튼, 선택 표시, 진행 막대, 완료 표시 |
