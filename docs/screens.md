# screens.md — 화면 설계서

## 요금제 목록

### 목적
중요하게 보는 조건을 선택하고 추천 요금제의 가격·혜택·프로모션을 비교한 후 상세 화면으로 이동한다.

### 라우트
/plans
- 제안 경로이며, 원본에는 라우트가 명시되어 있지 않다.

### 구성 요소
- 아래 컴포넌트 이름은 참고 이미지의 UI에 대응하는 라이브러리 이름이다. 이미지 자체에서 인스턴스 연결은 확인할 수 없다.
- Header:
  - Type=root
  - 화면 제목 “요금제”
- Logo: 헤더 우측 로고
- 신규: 목록 안내
  - “나에게 맞는 요금제를 골라보세요”
  - “중요하게 보는 조건을 고르면 추천해 드려요”
- FilterChip: 조건 선택
  - “데이터 많이”: selected
  - “가성비”: default
  - “구독 포함”: default
  - “통화 많이”: default
- 신규: 목록 요약
  - “추천순 · 4개”
  - 별도 정렬 선택 컨트롤은 이미지에 표시되어 있지 않다.
- Card/Plan: 요금제 목록
  - 첫 번째 카드
    - Name: 넉넉 무제한
    - Desc: 데이터 무제한 · 통화 무제한 · 넷플릭스 포함
    - Discount: 15%
    - Price: 월 85,000원
    - Original: 월 100,000원
    - Tag: “추천”
    - Chip: Type=sale, “24개월 할인 프로모션”
    - Button: “자세히”
  - 두 번째 카드
    - Name: 스탠다드 110
    - Desc: 데이터 110GB · 통화 무제한
    - Discount: 12%
    - Price: 월 69,000원
    - Original: 월 78,000원
    - Tag: “추천”
    - Chip: Type=sale, “24개월 할인 프로모션”
    - Button: “자세히”
  - 세 번째 카드
    - Name: 라이트 30
    - Tag: “추천”
    - 나머지 정보는 이미지 아래로 잘려 확인되지 않는다.
  - 네 번째 카드
    - 목록 요약에는 총 4개로 표시되어 있으나, 해당 카드의 내용은 이미지에 보이지 않는다.

### 상태
- 기본:
  - “데이터 많이” 조건이 선택되어 있다.
  - “추천순 · 4개”와 요금제 카드를 세로로 노출한다.
  - 정가는 취소선으로 표시하고, 할인율과 프로모션은 강조 표시한다.
  - 세 번째 카드는 화면 하단에 일부만 보인다.
  - 조건 변경 후 목록의 변화와 스크롤 동작은 정지 이미지에서 확인되지 않는다.
- 로딩: 원본에 정의되지 않음.
- 빈: 원본에 정의되지 않음.
- 에러: 원본에 정의되지 않음.

### 이동
- 들어오는 곳: 플로우 시작점 “진입”. 이전 화면은 명시되지 않음.
- 나가는 곳:
  - 카드의 “자세히” → 요금제 상세
  - 새 목록의 각 요금제와 기존 스탠다드 상세 시안 사이의 데이터 매핑은 정의되지 않음.
  - 조건 선택은 현재 화면의 UI이며 별도 화면 이동은 정의되지 않음.

## 요금제 상세

### 목적
선택한 요금제의 가격, 제공 혜택, 이용 기간과 갱신 조건을 확인하고 구독 신청으로 이동한다.

### 라우트
/plans/:planId
- 제안 경로이며, 원본에는 라우트가 명시되어 있지 않다.

### 구성 요소
- Header: 화면 제목 “요금제 상세”
- icon/arrowLeft: 헤더 뒤로 아이콘
- Card/Price:
  - 스탠다드
  - 월 9,900원
  - 부가세 포함 · 매월 정기 구독
- List/Row: 제공 혜택 3개
  - 이용 횟수: 월 30회
  - 기본 기능: 제공
  - 이용 기록: 확인 가능
- 신규: 구독 안내
  - 이용 기간: 신청일부터 1개월
  - 갱신 주기: 매월 자동 갱신
  - “이용 횟수는 매월 새로 제공되며, 남은 횟수는 다음 달로 이월되지 않습니다.”
- 신규: 하단 동작 영역
  - Button: “구독 신청”
  - Button: “뒤로”

### 상태
- 기본: 스탠다드 요금제의 가격, 혜택과 구독 안내를 노출한다.
- 로딩: 원본에 정의되지 않음.
- 빈: 원본에 정의되지 않음.
- 에러: 원본에 정의되지 않음.

### 이동
- 들어오는 곳:
  - 요금제 목록 → “자세히”
  - 구독 신청 → “취소”
- 나가는 곳:
  - “구독 신청” → 구독 신청
  - “뒤로” → 요금제 목록
  - 헤더 뒤로 아이콘의 별도 이동 규칙은 명시되지 않음.

## 구독 신청

### 목적
선택한 요금제의 신청 내용을 확인하고 신청자 정보를 입력한 후 구독을 신청한다.

### 라우트
/subscription/apply
- 제안 경로이며, 원본에는 라우트가 명시되어 있지 않다.

### 구성 요소
- Header: 화면 제목 “구독 신청”
- icon/arrowLeft: 헤더 뒤로 아이콘
- 신규: 신청 내용 요약 카드
  - List/Row: 요금제 / 스탠다드
  - List/Row: 월 요금 / 9,900원 (부가세 포함)
  - List/Row: 제공 혜택 / 월 30회 이용, 기본 기능 + 이용 기록
  - List/Row: 이용 시작 / 신청 완료 후 바로 이용
- Input: 이름, 표시 값 “김민수”
- Input: 이메일, 표시 값 “minsu@example.com”
- 신규: 신청 안내 문구
  - “신청 내용을 확인해 주세요.”
  - “구독은 신청일부터 매월 자동 갱신됩니다.”
- 신규: 하단 동작 영역
  - Button: “신청”
  - Button: “취소”

### 상태
- 기본: 신청 내용과 이름·이메일 입력란을 노출한다. 시안에는 김민수와 minsu@example.com이 입력되어 있다.
- 로딩: 원본에 정의되지 않음.
- 빈: 원본에 정의되지 않음.
- 에러: 입력 검증과 신청 실패 상태는 원본에 정의되지 않음.

### 이동
- 들어오는 곳: 요금제 상세 → “구독 신청”
- 나가는 곳:
  - “신청” → 신청 완료
  - “취소” → 요금제 상세
  - 헤더 뒤로 아이콘의 별도 이동 규칙은 명시되지 않음.

## 신청 완료

### 목적
구독 신청 완료와 이용 시작을 알리고 신청 결과를 확인한 후 신청 절차를 종료한다.

### 라우트
/subscription/complete
- 제안 경로이며, 원본에는 라우트가 명시되어 있지 않다.

### 구성 요소
- Header: 화면 제목 “신청 완료”
- icon/arrowLeft: 헤더 뒤로 아이콘
- 신규: 신청 완료 안내
  - “구독 신청이 완료되었습니다”
  - “김민수님의 스탠다드 구독이 시작되었어요.”
  - “지금부터 제공 혜택을 이용할 수 있습니다.”
- 신규: 신청 결과 정보 영역
  - List/Row: 신청 상태 / 완료
  - List/Row: 요금제 / 스탠다드
  - List/Row: 월 요금 / 9,900원 (부가세 포함)
  - List/Row: 제공 혜택 / 월 30회 이용, 기본 기능 + 이용 기록
  - List/Row: 이용 기간 / 신청일부터 1개월
  - List/Row: 갱신 주기 / 매월 자동 갱신
- 신규: 결과 안내 문구
  - “신청 결과는 minsu@example.com으로 안내됩니다.”
- 신규: 하단 동작 영역
  - “아래 확인을 누르면 신청 절차가 종료됩니다.”
  - Button: “확인”

### 상태
- 기본: 신청 상태 “완료”, 구독 정보와 결과 안내 이메일을 노출한다.
- 로딩: 원본에 정의되지 않음.
- 빈: 원본에 정의되지 않음.
- 에러: 원본에 정의되지 않음.

### 이동
- 들어오는 곳: 구독 신청 → “신청”
- 나가는 곳:
  - “확인” → 신청 절차 종료. 종료 후 도착 화면은 명시되지 않음.
  - 헤더 뒤로 아이콘은 시안에 있으나, 이동 대상은 플로우에 정의되지 않음.
